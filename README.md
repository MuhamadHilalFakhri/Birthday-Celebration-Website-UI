
  # Birthday Celebration Website UI

  This is a code bundle for Birthday Celebration Website UI. The original project is available at https://www.figma.com/design/qO0glXUtHg3QbVcIhHdwux/Birthday-Celebration-Website-UI.

## Running the code

Use Corepack so the repo runs with the pinned `pnpm` version from `package.json`.

Run `corepack pnpm install` to install dependencies.

Run `corepack pnpm dev` to start the development server.

Run `corepack pnpm build` to create a production build.
